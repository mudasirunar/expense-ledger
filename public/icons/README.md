# PWA Icons Directory

This directory holds the mobile and desktop PWA icon assets:
* `icon-192x192.png`: Android home screen & standard PWA launch icon.
* `icon-512x512.png`: Splash screen & high-DPI PWA icon.
* `apple-touch-icon.png`: iPhone Safari Home Screen bookmark icon (180x180).

Temporary PNG placeholders can be replaced with custom brand graphics.
